# KG-2 Book A — Book Notes

Third Speedy Scholars workbook. Sequel to KG-1 Book B. 35 pages (cover + 34),
landscape A4.

Reference: UCMAS KG-2 Book A
(`public/ucmas-books/KG-2 BOOK-A (1-24)Pages.pdf` + `KG-2 BOOK-A PAGES(25-34).pdf`).

---

## What This Book Teaches

Two major themes:

1. **Composition of 10 — Advanced** (pages 1-27). Revisits the +1 through +9
   complements but now with **larger operands that produce two-digit results**
   (e.g., 7+5=12, 9+4=13, 8+8=16). Introduces new dual-step formulas for the
   middle range:
   - `+6 = −4 + 10`  (5+6, 6+6, 7+6)
   - `+7 = −3 + 10`  (5+7, 6+7, 7+7)
   - `+8 = +3 − 5 + 10`  (5+8, 6+8) — **new two-step trick**
   - `+9 = +4 − 5 + 10`  (5+9) — **new two-step trick**

2. **Mental Calculation** (pages 28-34). The kid stops using the physical
   abacus and visualizes it: close eyes → imagine abacus → imagine beam →
   imagine rods → imagine beads. Includes a "Listening Exercise" sidebar
   so the teacher can call out numbers verbally.

## Calc Page Data Strategy

For Book A: 9 formula-introducing pages (3, 5, 9, 11, 16, 19, 24, 26) plus
1 wide-revision page (27). Standard layout = 8/8/4 + bottom strip with optional
mini-diagram on the formula pages. Bottom-strip problems must respect
"techniques learned" — by p3 the kid only knows up to ±9 with +5 to +9 tricks
from Book B, so problems can mix any of those.

For pages 30-34: switch to **Mental Calculation** layout = wide 10-col tables
without bottom strip. p31-34 add a 10-line "Listening Exercise" sidebar
(numbered 1-10) for the teacher.
