(age 5–6). Same format: 34 content pages + cover = 35 pages, landscape A4.

---

## What This Book Teaches

KG-1 Book A taught: abacus anatomy, numbers 1–10, direct ±1 to ±9, intro to
Composition of 5 (+1 to +4 partner).

**Book B is the natural sequel.** Two themes:

1. **Decomposition of 5** — the *subtraction* counterparts learned in Book A:
   - `−4 = +1 − 5`
   - `−3 = +2 − 5`
   - `−2 = +3 − 5`
   - `−1 = +4 − 5`

2. **Composition of 10** — adding to 10 using complementary pairs:
   - `+9 = −1 + 10`
   - `+8 = −2 + 10`
   - `+7 = −3 + 10`
   - `+6 = −4 + 10`
   - `+5 = −5 + 10`

After Book B, the student can do all single-digit ± fluently using bead-rod
mechanics, ready for two-digit numbers in KG-2.

## Pattern-Level Decisions (so I don't re-decide per page)

### Calculation pages (5, 6, 7, 8, 10, 11, 12, 13, 14, 15, 18, 19, 20, 21, 22, 23, 24, 27, 28, 29, 30, 31, 32 — that's 23 of 34)
- Same 3-table + bottom-strip layout as Book A
- All formula text in **top-left of header** (e.g., `−4 = +1 − 5`, fingering exercise to the right)
- New: **mini "trick diagram" in the bottom-strip area** for the formula-introducing pages (rows 5, 7, 10, 12, 19, 21, 23, 28, 31). Shows the conversion visually with 2 small abacuses. Replaces one of the 4 bottom-strip cards.
- Bottom-strip problem data **must** be unique per page (use the same `BOTTOM_STRIP_SETS` page-keyed dict pattern as Book A)
- Three-row operand data (1, 2, 3) — generated to stay within values the student has learned by that page (use −4 only on pages 5+, use +9 only on pages 19+, etc.)

### Concept pages (1, 2, 3, 4, 9, 16, 17, 25, 26, 33, 34 — that's 11 of 34)
- These are the "interest" pages with illustrations / visual exercises
- Each one needs custom layout; can't templatize. Each gets its own `page_NN()` function in generate.py.

## Implementation Notes

- `draw_cherry` was replaced by `draw_strawberry` throughout — `draw_cherry` renders cherry-pairs (2 visual cherries per call), confusing for counting pages.
- Bottom-strip `obj_s` is scaled dynamically by `(a + b)` so high-count problems (e.g. 9+6 on the +6 page) still fit inside the card.
- Page 9 stack values are slotted into a 4-row layout inside the box (start, op2, op3, answer underline) so all three operands and the answer line stay inside the visible box.
